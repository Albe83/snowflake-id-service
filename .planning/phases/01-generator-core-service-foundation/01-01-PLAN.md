## Trust Boundaries

| Boundary | Description |
|---|---|
| Process environment → config loader | NODE_ID and PORT are untrusted deployment inputs that control identity and listener binding. |
| HTTP client → temporary dev handler | Request method/path and generated output cross the local HTTP boundary. |
| OS signal → process lifecycle | External termination requests control shutdown sequencing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering | config.LoadFrom | high | mitigate | Parse and range-check explicit NODE_ID and PORT; fail before listener creation. |
| T-01-02 | Elevation of privilege | /dev/id | medium | mitigate | Bind the temporary server to the configured port through the composition root and expose only the single dev route. |
| T-01-03 | Tampering | Generator state | critical | mitigate | Guard lastMs and seq with one mutex and reject backwards time without state mutation. |
| T-01-04 | Information disclosure | boot logging | low | accept | node_id and epoch are intentional operational identity data; no secrets are read or logged. |
| T-01-SC | Tampering | Go module/dependency installs | high | mitigate | Keep go.mod stdlib-only and verify with go vet, go test, and dependency inspection before execution. |
